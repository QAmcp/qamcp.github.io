MCP prompt injection: what a test can and cannot find

Prompt injection is text that gets your AI to follow someone else's instructions. Through MCP it can arrive two ways: in a tool's description, or inside the answer a tool returns. A test can help with the first and much less with the second, and it's better to know which is which.

Sheet 2 of 4 · Two ways in

Two ways in

  1. In a tool's descriptionThe server's own text carries the instructions. It's there before you run anything, so it can be read and checked. This is tool poisoning.
  2. In a tool's answerThe tool fetches something from the outside world, like a web page, an email or a support ticket, and that content contains instructions. The server can be entirely honest, and the attack comes from whoever wrote the content. This changes with every call, so no test run today can see tomorrow's answers.
Sheet 3 of 4 · Can and cannot

What QAmcp can and cannot find

  • Can findKnown hidden-instruction wordings and invisible characters in tool descriptions
  • Can findSecrets in error messages, and what looks like a key in a tool's answer
  • Can findTools that can change or send things, from their labels and descriptions
  • Cannot findInstructions hidden inside live tool answers. We only look for those in descriptions
  • Cannot findHidden instructions worded in a way our list doesn't know yet
  • Cannot findWhat a tool does behind the scenes, or anything in its source code

So a clean result in the directory doesn't mean a server is immune to prompt injection. Any tool that brings in outside content can carry it. The full list is on what QAmcp can and can't see.

Sheet 4 of 4 · Limit the damage

How to limit the damage

Since no test catches everything, limit what a tricked AI could do.

  1. Connect only the tools you needFewer tools means fewer ways for something to go wrong. Check what a server can change before you add it.
  2. Keep approval prompts onLet your AI app ask you before anything that changes or sends something, and read what it asks.
  3. Don't mix the three risky thingsThe danger is highest when one AI session has private data, reads untrusted content, and can send data out. Remove any one of the three and an injected instruction can do much less.

Questions

What is prompt injection in MCP?

Prompt injection is text that gets your AI to follow someone else's instructions. Through MCP it can arrive in a tool's description, or inside what a tool returns, such as a web page or an email the tool fetched.

Can a test find prompt injection in an MCP server?

Partly. A test can read tool descriptions for known tricks. It can't predict what will be inside live answers later, because that content comes from the outside world at the moment you use the tool.

How do I limit the risk?

Connect only the tools you need, keep your app's approval prompts on for anything that can change or send things, and avoid giving one AI session private data, untrusted content and a way to send data out, all at the same time.
