Sheet 2 of 3 · Privacy policy

What we collect: nothing about you

The free tool (qamcp-cli)

  • It runs on your computer and talks only to the MCP server you choose, and to that server's login service if it has one.
  • It sends nothing to us: no usage data, no reports, no error logs, no analytics.
  • If you log in with --login, the login pass is saved on your own computer, in a .qamcp folder, and nowhere else. Delete that folder to remove it.
  • Reports are written only to the files you ask for, on your computer.

The GitHub check

It runs inside your own GitHub account, on GitHub's computers, under GitHub's own terms. It comments only on your own pull requests. We receive nothing from it.

This website

  • No analytics, no cookies, no ads, no tracking scripts. The fonts are served from this site.
  • The site is hosted on GitHub Pages. Like any web host, GitHub may keep basic technical logs (such as IP addresses) to run and protect its service. We don't receive or use them. See GitHub's privacy statement for details.

When we test public servers

  • We test new servers from the official MCP Registry, in safe mode (read-only tools only), and tell their owners what we found.
  • To do that we keep the test result, and the public contact details listed on the server's own website or registry page, such as a contact email or company page.
  • Report links we send are unlisted and hidden from search engines.
  • If you own a server and want us to stop testing it, remove a report, or delete the contact details we used, tell us (see Contact) and we will.

Changes

If this ever changes, for example when we add accounts to a hosted version, we'll update this page first and change the date at the top.

Sheet 3 of 3 · Terms of use

Using QAmcp

The software

QAmcp is free and open source under the MIT license. You may use, copy, change and share it. As the license says, it comes as is, without warranty of any kind.

Test only what you're allowed to

Use QAmcp on servers you own, servers you have permission to test, or public servers in their normal, intended way. You are responsible for how you use it, including any options that run more tools, such as --owner or --run-unlabeled. Use those only on your own server or a test copy.

Results

QAmcp reports facts it measured, such as pass or fail, timings and exact matches. It can still be wrong about a server, especially one that behaves in an unusual way. A report is a starting point to check, not a guarantee that a server is safe or unsafe. If a result looks wrong, tell us and we'll fix it.

Names and other servers

Servers shown as examples on this site were tested independently. QAmcp is not affiliated with, or endorsed by, their owners.

Contact

For anything on this page, including removing a report or contact details, open an issue on GitHub, or reply to the email we sent you.
