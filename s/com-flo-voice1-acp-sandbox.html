What it can do

8 tools, in the server's own words.

list_productsread-only

List everything the demo store sells, with product ids and prices.

create_checkout

Start a checkout (an Agentic Commerce Protocol checkout session) with the products and quantities the user wants.

update_checkout

Replace the items in an open checkout (e.g.

get_checkoutread-only

Read the current cart, total, payment status and order of a checkout.

request_paypal_payment

Create a PayPal (sandbox) payment for the checkout's exact total.

wait_for_payment_approvalread-only

Wait (up to 45s per call) until PayPal reports the user approved the payment.

complete_checkout

Place the order.

cancel_checkout

Cancel an open checkout.
