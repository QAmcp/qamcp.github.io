A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

26 tools, in the server's own words.

search_jobsread-only

Search the jobs that match the user's résumé and filters, best match first, a page at a time.

get_jobread-only

The full posting, the match assessment against the user, and any application status.

get_jobsread-only

Up to 20 postings by id with their match assessments, descriptions shortened; ids not found come back in missing.

get_job_from_link

Reads the posting at an employer or job-board link, keeps it in the user's saved jobs and returns it with its match assessment and job id.

searchread-only

Search the jobs matching the user's résumé, best match first, as citable results with the employer's posting URL; fetch returns a result's full text.

fetchread-only

The full text of one job from search, with its posting URL and match details.

list_applicationsread-only

The user's applications, newest first, with status and the employer's receipt when sent.

list_pending_questionsread-only

Questions employers asked that only the user can answer; the applications asking them wait.

get_accountread-only

The user's plan, applications left this week and today (or unlimited), and anything stopping applications from being sent.

get_profile_statusread-only

What the user's Applysent profile still needs before applications can go out, and how many employer questions wait.

list_inboxread-only

get_messageread-only

One email from the application inbox with its text and the application it belongs to.

get_threadread-only

Every email of the same application as the given one, or of the same sender and subject when it belongs to none, oldest first, without bodies.

answer_question

Saves the given answer to one open question and applies it to every application asking it; those applications then continue.

preview_tailored_resume

The résumé tailored to one job, as the PDF an application would attach, with what changed against the saved résumé.

approve_tailored_resume

Marks the previewed tailored résumé (by its resume_sha256) as the one to send with this job's application.

regenerate_tailored_resume

Discards the job's tailored résumé and its approval and tailors it again with an AI model from the saved résumé.

preview_applicationread-only

What applying to one job would send and use, and a single-use confirmation_token for apply_to_job.

apply_to_job

Sends a real application to one job on the employer's site and uses one application from the user's plan.

cancel_application

Stops an application whose send has not started; it can then never be sent and its open questions are withdrawn.
