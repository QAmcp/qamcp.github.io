A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

24 tools, in the server's own words.

rayana_ai_rankingsread-only

Latest ranked candidate batch for a lane: daily (the main research lane), turtle (breakout system), or mr (mean-reversion).

rayana_ai_lanesread-only

Which lanes (daily/turtle/mr) currently have a batch available.

rayana_ai_signalsread-only

Latest aggregator-consensus batch for one asset lane: which tickers cleared the signal pipeline, blended agg_score, confirming source count.

rayana_ai_consensusread-only

Per-source consensus snapshots (insider trades, congressional trades, earnings beats, dated catalysts, on-chain flows, 13F filings, AI news-beneficiary reads).

rayana_ai_tickerread-only

Full per-ticker research view: score, lane membership, per-source signals, virality, consensus, cluster-rotation position, forward returns.

rayana_ai_ticker_priceread-only

Daily close-price history for one ticker over the given period.

rayana_ai_ticker_analystread-only

The ticker's current AI analyst read (lean, conviction, thesis, six fixed sections, evidence for/against, invalidation condition).

rayana_ai_analyst_readread-only

Open a ticker's AI analyst read: the current one, or a new one generated on the spot when the ticker has none (this can take about half a minute).

One ticker's published article history, newest first.

rayana_ai_rotationread-only
