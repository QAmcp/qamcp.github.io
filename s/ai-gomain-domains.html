What it can do

15 tools, in the server's own words.

check_availabilityread-only

Check whether domain names are registered, asking each TLD's registry directly (RDAP).

compare_pricesread-only

Every tracked registrar's price for one TLD, in US dollars per year, refreshed daily from 40+ registrars.

suggest_namesread-only

Turn a few keywords into domain name candidates (the words joined, with common prefixes and suffixes, across several TLDs), check each with its registry, and r…

tld_inforead-only

Who runs a TLD, its type (generic, country-code, ...), when it was delegated, its registry's website and lookup servers (from IANA), and its cheapest first-yea…

price_historyread-only

Every recorded price change for one TLD, oldest first, from GoMain's daily archive.

check_nameread-only

Is a project name usable everywhere it'll be needed?

dns_setupread-only

The exact DNS records to add so a domain serves a website (Vercel, Netlify, GitHub Pages, Cloudflare Pages) and receives email (Google Workspace, Microsoft 365…

appraise_domainread-only

A rough value range for a domain, from its length, how easy it is to say, its TLD, its age and how many popular TLDs have the same name registered.

acquisition_reportread-only

For a domain someone already owns: whether it's listed for sale and where (with the asking price when the sale page shows one), when it could drop, its estimat…

request_acquisition

Ask GoMain's brokerage to acquire a domain someone else owns.

search_domains_for_saleread-only

Search domains their owners have listed for sale with GoMain (each owner proved control of the name).

make_offer

Offer to buy a domain listed with GoMain.

list_domain_for_sale

List a domain the user owns for sale.

watch_domain

GoMain checks a domain daily and emails when it drops (or is about to), changes hands, or is listed for sale.

broker_statusread-only

The status and history of a brokerage deal (id d_…) or a watch (id w_…), given the id and status key returned when it was created.
