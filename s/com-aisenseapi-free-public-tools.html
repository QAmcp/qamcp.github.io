What it can do

60 tools, in the server's own words.

get_current_timeread-only

Get the true current date and time, as an ISO 8601 string and a Unix timestamp, for any timezone.

generate_uuidread-only

Generate one random RFC 4122 version 4 UUID.

shorten_url

Turn a long URL into a short 307.fi link that redirects to it.

store_temporary_data

Put any JSON value somewhere another process can fetch it, and get back a storage_id plus a public read_url.

read_temporary_dataread-only

Fetch back a JSON value that store_temporary_data saved earlier, in this session or in another one.

create_webhook_capture

Create a throwaway URL that records the next HTTP request anyone sends to it, headers and body included.

read_webhook_captureread-only

Check whether anything has been sent to a capture URL yet, and read it.

create_human_approval

Put a decision in front of one to twenty people.

read_human_approvalread-only

Check whether the person has answered a form from create_human_approval, and read the answer.

create_agent_wake

Create a durable MCP task that completes when a webhook arrives, a person answers a form or a chosen time is reached.

create_heartbeat

Create a deadline monitor for a job, device or agent that should keep checking in.

read_heartbeatread-only

Read one heartbeat immediately.

ping_heartbeat

Record a check-in for an armed heartbeat and move its next expected deadline.

create_lease_namespaceread-only

Create a random private namespace before several agents coordinate work using short readable keys.

acquire_lease

Claim one unit of work so concurrent agents do not perform it twice.

renew_lease

Extend a lease that this caller still owns.

release_lease

Give up a lease before its TTL ends so another agent can acquire the work.

complete_lease

Finish owned work and save a reusable JSON result for later callers with the same identity and fingerprint.

create_agent_inbox

Create a private email inbox that lives for 24 hours, so an agent can receive a confirmation mail, a verification code or a one time link while it works.

read_agent_inboxread-only

Read the mail that has arrived in an inbox from create_agent_inbox.

create_agent_queue

Create a small temporary pull queue for cooperating agents.

read_agent_queueread-only

Read queue metadata and pending, claimed, completed and failed counts using the read token.

enqueue_agent_queue_job

Add a JSON job using the write token and a stable job_key.

read_agent_queue_jobread-only

Read one known job, its JSON payload and status using the read token.
