A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

Known security advisories

It lists no public code, so there is nothing to look up in GitHub Security Advisories or OSV.dev. QAmcp tests how a server behaves. It does not scan source code.

What it can do

10 tools, in the server's own words.

searchread-only

Search Graunt's catalog of evaluated data from many sellers.

fetchread-only

Read one Graunt catalog packet by id.

search_assetsread-only

Search the public catalog and return listing rows as Graunt's API gives them (GET /v1/listings), paginated.

get_assetread-only

Read one listing by id as Graunt's API gives it (GET /v1/listings/{id}).

get_agent_commerce_manifestread-only

Read the agent commerce manifest for a listing: price, rights, and how to buy it.

get_asset_manifestread-only

Read the canonical asset manifest (sha256-stamped).

get_bundle_manifestread-only

Read the per-asset bundle inventory: every delivered file with role, format, size and content hash, plus counts that name the population each one counted.

meta_capabilitiesread-only

Read /v1/meta/capabilities: what Graunt offers to an agent, in machine-readable form.

meta_refinery_support_matrixread-only

Read /v1/meta/refinery-support-matrix: the source types Graunt accepts and what the Refinery does with each.

match_video_specread-only

Find out how many hours of video on Graunt meet a spec, and in which categories.
