What it can do

18 tools, in the server's own words.

browser_workspaceread-only

Show your active browsers and saved sessions in a workspace beside the conversation.

resume_saved_session

Resume an existing saved session owned by the connected account.

open_browser

Open one remote browser in the cloud with the connected CloudBrowser account.

close_browser

Close a specific browser

get_browsersread-only

Get list of active browsers

start_remote_desktop

Start remote desktop access to a browser

stop_remote_desktop

Stop remote desktop access to a browser

get_saved_sessionsread-only

Get list of saved sessions

remove_saved_session

Delete a saved session

connect_to_browser

Connect to CloudBrowser browser for direct control

navigate_to_url

Navigate the connected browser to a URL that the user asked for.

get_page_contentread-only

Get the HTML content of the current page to answer the user's request about it.

click_element

Click on a page element

type_text

Type text into an element

get_elementsread-only

Get information about elements matching a selector

take_screenshotread-only

Take screenshot of the current page

disconnect_browser

Disconnect this control session from a browser.

get_connected_browsersread-only

List the browsers that this caller has connected for direct control
