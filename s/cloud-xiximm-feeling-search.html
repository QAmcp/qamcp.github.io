What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

5 tools, in the server's own words.

word_analyzeread-only

把一句中文/英文口语描述解析成感受词与视觉风格。默认纯本地词典（免费、不联网）；本地一个词都没命中且允许时，才上云。返回 score 是相对值不是概率，styles[].matched 是可以直接引用给用户看的命中词。

word_lookupread-only

查一个感受词：落在哪些风格、对立词是什么、常一起出现的词、是否标识词。纯本地查表。

word_listread-only

列出全部感受词（带共享度）或视觉风格（带定义与词集规模）。调 analyze 之前先拉一次可避免名字拼错。

style_getread-only

按风格 id（或中文名）取一个风格：定义、生成用提示词、感受词、年代地域，以及它对应的图片（thumb 320 / full 960 绝对地址，带 kind/credit/license）。kind=work 是有出处的真作品，synthetic 是 AI 示意，placeholder 是占位图。

word_statusread-only

返回词表版本、规模（词/风格/变种/挂靠率）以及是否配置了云端额度。
