What it can do

12 tools, in the server's own words.

haggl_list_vendorsread-only

List vendors that accept AI-agent price negotiations through haggl.ai.

haggl_start_negotiation

Start a price negotiation with a vendor.

haggl_search_catalogread-only

Search a vendor's catalog so the offer can name exact products, then follow the how_to_ask field of the result.

haggl_get_negotiationread-only

Read the canonical state, current offer version, guidance and permitted actions of an existing negotiation.

haggl_submit_offer

Request a quote using all context already available.

haggl_accept_offer

Accept the vendor's offer and lock in the deal.

haggl_search_discountsread-only

Find merchants that run a sales agent on haggl.ai, by business name, website or kind of product.

haggl_create_haggl_id

Create a haggl ID for the user, so offers and codes from different merchants stay together and can be read back later.

haggl_request_haggl_id_confirmation

Get a link for the user to read the haggl ID consent text and confirm it on haggl.ai, when they are not in this conversation to agree to it.

haggl_get_my_offersread-only

Read what haggl.ai holds for the user's haggl ID: when it was created and the negotiations, offers and codes linked to it, newest first.

haggl_get_bids

Have the merchants on haggl.ai in one shopping category (for example travel) bid for the user at once, from their haggl ID record, without new proof.

haggl_delete_haggl_id

Delete the user's haggl ID and unlink the offers linked to it.
