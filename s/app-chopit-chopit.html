get_menu_draft

Returns the current state of a menu draft: dinner slots and their labels, the offered choices, what is selected and locked, servings and slotIssues.

revise_weekly_menu

Changes a menu draft and returns the updated draft with a new menuDraftId; unrelated dinners, locks, dietary rules and pantry choice are kept.

save_week

Canonical saving operation.

list_saved_weeksread-only

Lists the user's Saved Weeks with their dinners and savedWeekId, for browsing or picking a week to reuse.

rename_saved_week

Renames one of the user's Saved Weeks by savedWeekId.

delete_saved_week

Permanently deletes one of the user's Saved Weeks by savedWeekId; irreversible, so it suits an explicit request that names the week.

save_discovered_recipe

Saves a Chop It catalogue recipe, unchanged, into the user's own library, reusing the existing copy if they already saved it.
