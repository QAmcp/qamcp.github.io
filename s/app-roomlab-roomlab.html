A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

19 tools, in the server's own words.

virtual_stage_room

Use only when the user wants furniture and decor added to an empty room.

change_room_style

Use only when the user wants a furnished room restyled while keeping its furniture arrangement.

declutter_room

Use when the user wants clutter and visual mess removed while keeping the major furniture and architecture.

empty_room

Use when the user wants all furniture, appliances, and decor removed so the room appears vacant.

replace_furniture

Use when the user wants one furniture item replaced with the item shown in a reference image.

replace_material

Use when the user wants the material on a wall, floor, rug, curtain, countertop, backsplash, or another surface changed to match a reference image.

render_interior

Use when the user wants an interior sketch, model view, or design image turned into a photorealistic architectural render.

render_exterior

Use when the user wants an exterior sketch, model view, or design image turned into a photorealistic architectural render.

custom_prompt

Use for the workspace Custom Prompt mode when another named RoomLab mode does not match.

set_sky_blue

Use when the user wants a dull or cloudy sky changed to a clear bright blue sky while preserving the property and landscaping.

fill_and_clean_pool

Use when the user wants a pool filled with clean water and the surrounding pool area tidied.

clean_garden

Use when the user wants weeds and debris removed so a garden or outdoor area looks neat and maintained.

make_grass_greener

Use when the user wants dry or patchy grass refreshed so the lawn looks green and healthy.

visualize_wall_colors

Use this when the user wants to compare paint colors on the walls of the same room.

create_video_walkthrough

Use when the user wants one room photo animated with a camera move or other described effect.

create_video_transition

Use when the user wants an animated transformation from a start image to an end image.

create_house_tour

Use when the user wants a cinematic tour made from three to six room images in order.

upscale_room_image

Use this when the user asks to make an existing RoomLab image 4K.

get_generationread-only

Check a RoomLab.app creation and return status or finished media as data, without opening another card.
