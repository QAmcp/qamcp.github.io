What it can do

12 tools, in the server's own words.

find_capsuleread-only

Covers: 163 guided journeys across 17 areas: Finance (33, e.g.

list_categoriesread-only

Lists the areas the published guided journeys cover: each category slug, a readable label, how many journeys it holds and a few example titles.

browse_catalogread-only

Pages through the published guided journeys, optionally within one category (a slug from list_categories), featured first.

open_journey

Opens (or resumes) a guided journey and returns the session contract: `session` (keep it), the stop list (titles only), the capabilities, the limits in turns, …

turn

Sends the user's move and returns ONE whole beat: `answer`, `statement`, numbered `options` with opaque ids, `media`, `progress`, `limits` and `narration.text_…

journey_stateread-only

Where the user is in the journey: position (stop, visited of total), `remaining` (stops left, percent done, and each top-level topic's visited of total), mode,…

make_artifact

Composes the user's takeaway (kind "takeaway") from THIS conversation: what they asked, what landed, the stops they visited.

handoff

Mints a resume link and code for this session so the user can continue on the website or in another assistant.

restart_journey

Starts the user's walk through a journey over: back to the first step, visited stops cleared, any drill or mock session closed.

account_statusread-only

Whether this connection is bound to an account, whether that account includes the premium journeys (`premium`, a flag) and unlimited web turns, the assistants …

account_bind

Starts binding an account for the user without a web visit.

account_verify

Completes account_bind: pass the challenge it returned and the code the user read you (digits only; spaces are fine).
