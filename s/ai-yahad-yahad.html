What it can do

4 tools, in the server's own words.

list_occasionsread-only

Lists the occasions this group-card service supports, with the value to pass to create_board.

suggest_promptsread-only

Suggests ready questions the organiser can show participants, for an occasion.

board_statusread-only

Shows how collection is going for a card: how many have signed, when collection closes and when it opens.

create_board

Creates a group greeting card that several people sign before it opens on a set date, and returns the link to send to participants.
