What it can do

8 tools, in the server's own words.

search_businessesread-only

Use this when the user wants to find a local home-service business or appointment: plumber, HVAC, electrician, gate, fence, or security install, pole barn, or …

get_businessread-only

Use this when the user wants to read one enrolled local home-service business and search_businesses or resolve_business already returned its id.

resolve_businessread-only

Use this when the user wants to resolve one enrolled local home-service business from a domain, a place, or a phone number.

check_availabilityread-only

Use this when the user wants to check availability for a local home-service appointment before booking.

request_booking

Use this when the user wants to book a local home-service appointment and has already chosen an open time.

get_booking_statusread-only

Use this when the user wants to check the status of a local home-service appointment.

request_serviceread-only

Use this when the user wants to open a quote form for a local home-service business rather than book a confirmed appointment time.

submit_service_request

Sends the user's quote request (name, email, optional phone, service location, preferred time) to the chosen business.
