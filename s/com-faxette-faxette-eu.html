A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

15 tools, in the server's own words.

open_fax_review

Open the private upload and PDF review interface for an account fax before approving payment.

get_fax_reviewread-only

No description given.

prepare_fax_upload

No description given.

update_fax_review

No description given.

get_capabilitiesread-only

Use this before preparing a fax to check this region's supported countries, languages, file limits and current retail and credit pricing rules.

lookup_fax_numberread-only

Search Faxette's catalog by agency, form number or purpose.

get_fax_reportread-only

Use this when the person asks for a delivery report or the transmitted document.

resend_fax

Use this only after the person asks to resend a failed fax and confirms its destination, including any corrected number.

create_document

Use this to add a file the person gave you to a fax: a PDF, or a photo saved as JPG, PNG, WEBP or HEIC, up to 20 MB.

create_fax

Use this once the person has confirmed the fax number, and given you their email if they aren't signed in.

get_fax_statusread-only

Use this when the person asks how their fax is doing, or to see whether it's ready to pay.

get_accountread-only

Use this to see which Faxette account the person signed in with: their name, email, credit, and whether it's the US or EU copy.

get_faxesread-only

Use this when the person asks about faxes they've sent from their Faxette account, like what they sent last week or which faxes failed.

get_faxread-only

Use this for one fax from the person's Faxette account: its status, price, payment, documents' file names and history.

send_fax

Use this to send a fax from the person's Faxette credit.
