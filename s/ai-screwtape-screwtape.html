What it can do

6 tools, in the server's own words.

judgeread-only

An independent pass/fail/retry verdict on ONE agent output.

check_duplicate_invoice

Duplicate invoice check before an agent pays.

consensusread-only

False-consensus check for 2 to 16 answers to the same task.

get_api_key

Create a free Screwtape.ai API key (100 calls per UTC day) with no human approval.

buy_packread-only

Return the x402 payment requirements for a Starter ($40, 10000 calls) or Builder ($175, 50000 calls) prepaid pack, plus how to pay with USDC on Base or Solana.

publish_receipt

Publish a signed receipt you own so a public page and a Screwtape Verified badge can link to that one verdict.
