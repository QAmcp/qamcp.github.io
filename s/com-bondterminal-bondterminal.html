bondterminal_search_bondsread-only

Search and screen bonds by free text and REST-compatible filters; optionally return facets.

bondterminal_get_bondsread-only

Bond rows include stored optionAdjustedSpread and oasStatus when available.

bondterminal_calculateread-only

Results include live optionAdjusted OAS with model assumptions when a curve is available.

bondterminal_get_historyread-only

Return daily price, YTM, YTW, and spread history for one bond using a named range or explicit dates.

Return the current Argentina country-risk spread and deltas, with optional history.

bondterminal_treasury_curveread-only

Return the current US Treasury curve across 11 standard tenors.

Return the authenticated plan, calculation/read usage, remaining quotas, and reset time.
