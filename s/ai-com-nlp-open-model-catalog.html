What it can do

search_modelsread-only

Search curated open-weight model release records by model name, developer, license, parameter or context description, and technical features.

recent_modelsread-only

Return the newest curated open-weight model release records, optionally limited to releases on or after an ISO 8601 date.

get_modelread-only

Return the complete curated record for one model or model-family release, addressed by the slug returned from search_models or recent_models.
