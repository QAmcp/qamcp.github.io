What it can do

5 tools, in the server's own words.

sanitize_text

Deterministic Unicode/control-noise normalization and selected instruction-pattern flags.

structure_json

Parse JSON or a complete JSON code fence.

clean_markdown

Extract text from HTML while ignoring script/style content and normalize documented formatting artifacts.

chunk_document

Prefer paragraph/sentence boundaries, then split deterministically.

clean_and_chunk

Compound utility: Cleans markdown artifacts and semantically chunks documents in one atomic transaction.
