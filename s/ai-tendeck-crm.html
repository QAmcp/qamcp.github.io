What it can do

9 tools, in the server's own words.

describe_product

Plain-language description of the two Nuvidian products (P1 brokerage recruiting CRM, P2 agent CRM), what is free, and what the product never does.

get_free_limits

What each product includes for free, in plain numbers (P1: full pond + pipeline, 3 recruiters; P2: unlimited people/deals, no AI quotas because Tendeck runs no…

list_addons

Optional paid add-ons with their unit and price in cents.

start_workspace

Sign up for free: create a pending workspace and send a 6-digit code to the user's email (preferred) or US phone.

verify_phone

Finish signup: check the 6-digit code the user received by email (or text), activate the workspace and return a session token.

p1_practice_deck

Show a sample of Nuvidian P1's 'Today's 10' deck built from fictional Florida agents, so a human can see what the product does before signing up.

p2_practice_today

Show a sample of Nuvidian P2's Today's 10 built from fictional people, so a human can see what the product does before signing up.

tendeck_help

Answer any how-to or support question about Tendeck (sign-in, password, billing, connecting ChatGPT/Claude, importing, texting, privacy).

connectors_catalog

What Tendeck plugs into: live connectors, the next ones being built, and what is planned, each with what it gives the agent and how to connect.
