What it can do

12 tools, in the server's own words.

lookup_ip

Query complete IP intelligence: geolocation, ISP, ASN, IP type (residential/datacenter/mobile/VPN/proxy/Tor), risk score, and IPIPAI composite score (0-100 wit…

check_ip_reputation

Check IP reputation: proxy/VPN detection, Tor exit node, blacklist status, hosting/datacenter classification.

check_service_access

Check if a specific service (ChatGPT, Claude, Netflix, Disney+, etc.) is accessible from a given IP location.

rate_ip_node

Comprehensive rating for VPS, proxy nodes, and datacenter IPs.

score_ip_node

Score the quality and reliability of an IP/node using IP intelligence and network signals.

lookup_ip_location

Quick IP geolocation lookup via OpenIPAPI.

resolve_dns

Resolve a domain name to its A (IPv4) and AAAA (IPv6) DNS records.

ping_host

Send ICMP ping packets to a host and measure latency.

trace_route

Trace the network path from the server to a target host.

lookup_domain_whois

Query WHOIS registration info for a domain name or IP address.

lookup_mac_vendor

Identify the manufacturer of a network device by its MAC address using the OUI database.

check_website_availability

Check if major websites (Google, GitHub, YouTube, Wikipedia, etc.) are accessible from the server location.
