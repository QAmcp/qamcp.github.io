What it can do

17 tools, in the server's own words.

session_status

Verify Slack mobile session (run before other tools).

list_channels

List Slack channels and group DMs (mobile client.channels).

channel_info

Channel name and member count for a channel id.

list_channel_members

List member user ids in a Slack channel.

list_workspace_users

List users in the workspace.

search_people

Search people by name or email fragment.

post_message_rich

Post using mobile Block Kit blocks (message_blocks_json).

thread_replies

Read messages in a thread.

reply_thread

Post a reply in a thread.

delete_message

Delete one of your messages.

post_message

Post a message to a Slack channel or DM using the mobile user session.

conversation_history

Fetch recent messages in a channel.

open_conversation

Open a DM conversation with a Slack user id.

create_channel

Create a channel (may be restricted on some workspaces).

user_boot

Workspace client bootstrap after login.

list_workspaces

List workspaces after email confirmation.

confirm_email_signin

Start Slack email sign-in.
