A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

7 tools, in the server's own words.

upload

Upload one HTML/code payload and get a public share URL plus an edit token.

upload_site

Publish a multi-file static site from an authenticated account.

list_assetsread-only

List up to 50 assets owned by the authenticated user, newest first, with id, filename, timestamps and share URL.

viewread-only

Fetch a single asset by id and return its content, filename, creation time and share URL.

delete

Permanently delete one of your own assets by id.

get_inforead-only

Return Oh My Share service metadata: version, REST and MCP endpoints, feature list, and per-IP rate limits (10 uploads/hour, 500 views/hour).

search_galleryread-only

Search public gallery works by keyword across title, description, tags and id; omit query to browse the newest works.
