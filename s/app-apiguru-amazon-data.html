What it can do

12 tools, in the server's own words.

product_detailsread-only

Use for one product's current listing.

product_reviewsread-only

Use for what customers say about one product.

searchread-only

Use to find products by keyword and filters.

product_details_batchread-only

Use to enrich a list of ASINs in one call; compare the ASINs in `results` with the ones you sent.

offers_stockread-only

Use to compare sellers' current offers and see who holds the buy box, and, with check_inventory, how many units a buyer can add to the cart now.

best_sellersread-only

Use for what sells best in a department right now.

dealsread-only

Use for items currently promoted in Amazon's deals feed.

seller_profile_batchread-only

Use to vet sellers: name, rating and feedback counts as Amazon displays them.

seller_productsread-only

Use to list one seller's storefront.

seller_reviewsread-only

Use for a seller's customer feedback (service, shipping).

list_capabilitiesread-only

List every Apiguru endpoint with its price, required parameters and supported marketplaces, plus your current access mode, cache and session budget.

send_feedback

Report a bug, ask for a field, or say what would make this API more useful.
