60 tools, in the server's own words.

hgr_get_authenticated_userread-only

Reads the authenticated HGR user profile visible to the web app.

hgr_list_channelsread-only

Lists the user's connected stores/channels with channelOAuthId, store name, marketplace, country and connection status.

hgr_get_subscription_summaryread-only

Reads the visible current subscription/quota summary.

hgr_get_active_listingsread-only

Lists active listings for the selected visible store/channel.

hgr_get_pending_listingsread-only

Lists pending listings for one visible store.

hgr_get_terminated_listingsread-only

Lists terminated listings for one visible store.

hgr_get_listingsread-only

Gets exact listings only by concrete HGR listing ids or visible marketplace primary ids.

hgr_generate_limited_products_csvread-only

Generates the only product CSV allowed by MCP policy.

hgr_update_listing

Changes editable fields of one exact listing variation using HGRApi SaveProductChanges.

hgr_force_refresh_listings

Requests ForceRefresh for visible Product IDs.

hgr_list_pending_now

Publishes one pending listing immediately by its visible pending listing id.

hgr_pause_pending_to_review

Moves one pending listing to manual review by its visible pending listing id.

hgr_remove_listing

Removes or retires one listing by visible Product ID, or a pending listing by the visible pending listing id.

hgr_terminate_listing

Terminates one active listing by visible Product ID.

hgr_relist_listing

Relists one terminated listing by visible Product ID.

hgr_get_listing_price_historyread-only

Reads price history for one exact listing variation.

hgr_get_listing_stock_historyread-only

Reads stock history for one exact listing variation.

hgr_search_ordersread-only

Searches orders/order lines by visible order Reference and optional visible store.

hgr_load_order_progressread-only

Reads progress for an order resolved from visible order Reference.

hgr_load_order_addressesread-only

Loads available shipping addresses for an order resolved from visible order Reference.

hgr_set_shipping_address

Sets/corrects the shipping address for an order resolved from the visible order Reference.

hgr_process_order_lines

Starts normal processing for orders resolved from visible order Reference.

hgr_force_process_order_lines

Forces processing for orders resolved from visible order Reference.

hgr_stop_order_lines

Stops orders resolved from visible order Reference.
