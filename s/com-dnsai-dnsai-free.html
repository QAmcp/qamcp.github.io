A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

11 tools, in the server's own words.

dns_lookupread-only

Look up live DNS records for ONE domain.

email_security_checkread-only

One call answers "is this domain's email properly secured?" — checks MX, SPF, DMARC and mail-gateway/provider detection for ONE domain.

whois_lookupread-only

WHOIS / RDAP registration data for ONE domain or IP — registrar, status, creation/expiry, name servers.

spf_analyzeread-only

Analyze a domain's SPF record for ONE domain — the include tree and the RFC 10-DNS-lookup-limit verdict.

dmarc_checkread-only

Fetch and parse the DMARC policy for ONE domain — presence, p= policy, and the raw record.

validateread-only

Validate the SYNTAX of an SPF or DMARC record string (no DNS lookup) — returns valid/invalid, a score, a letter grade, and a parsed breakdown.

dkim_discoverread-only

Discover the DKIM signing keys published for ONE domain.

blacklist_checkread-only

Check whether ONE domain or IP is listed on major email blacklists / RBLs (Spamhaus, Barracuda, SpamCop, SORBS, UCEPROTECT and more).

searchread-only

Search DNSai for a domain.

fetchread-only

Fetch a DNSai result document by id (from search).

request_api_key

Get a FREE DNSai API key that raises the daily limit from the small shared anonymous allowance to 100 lookups/day.
