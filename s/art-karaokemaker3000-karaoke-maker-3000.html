A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

11 tools, in the server's own words.

get_accountread-only

Get the connected Karaoke Maker account, existing balance and supported Quick features.

prepare_karaoke

Import the user's selected MP3 and prepare a free Quick draft with a price quote.

create_local_upload

Authorize a short-lived upload of the user's selected local MP3.

start_karaoke

Start the quoted Quick karaoke after the user confirms its price and visual preferences.

get_karaokeread-only

Read a Quick project's authoritative status, progress, allowed actions and current MP4 links.

show_karaokeread-only

Show the compact Quick card.

refresh_karaoke_quote

Refresh an expired, unstarted project's quote and status.

list_karaokesread-only

List the connected account's Quick projects to find work to continue in this chat.

retry_karaoke

Retry a failed or stale Quick stage only when can_retry is true.

cancel_karaoke

Cancel this Quick workflow when can_cancel is true.

open_in_studio

Hand this project from automatic Quick processing to the full Studio editor when the user requests manual correction.
