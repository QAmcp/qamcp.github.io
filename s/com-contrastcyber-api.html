A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

38 tools, in the server's own words.

healthread-only

Database freshness: CVE/KEV/CWE counts and latest entries, and the sync state of each upstream feed.

cve_lookupread-only

Full CVE record by ID (CVSS, EPSS, KEV, CWE, references, CISA SSVC, Nuclei templates), with the optional GitHub Security Advisory.

cve_lookup_bulkread-only

Look up many CVEs at once, each with the fields of cve_lookup.

cve_productsread-only

The products a CVE affects, one page at a time, with the vulnerable products first.

cve_searchread-only

Search CVEs by severity, CWE, CVSS, EPSS, CISA KEV, ransomware use, Nuclei template, vendor, product and publish date, one page at a time.

cve_leadingread-only

List the CVEs most likely to be exploited, by EPSS score (the probability of exploitation in the next 30 days), with a verdict on the top score.

kev_lookupread-only

CISA KEV catalog entry for a CVE: the required action, the patch deadline and known ransomware use.

cwe_lookupread-only

CWE weakness details (description, mitigations, examples, OWASP Top 10 category in 2021 and 2025), with how many CVEs and CISA KEV entries name it.

cve_risk_scoreread-only

Composite risk score of a CVE, 0-100, for patch priority.

cve_exploitread-only

Public exploit intelligence (GitHub PoCs, Metasploit, NVD and CNA exploit references, ExploitDB).

cve_triageread-only

Rank the CVEs of a vendor or product by composite risk score, at or above the optional min_risk_score argument, as lean rows (cve_id, risk_score, label).

epss_risersread-only

List the CVEs whose EPSS score rose most over the last 7 or 30 days, with the old and the new score.

cve_triage_bulkread-only

Triage many CVEs at once, ranked by composite risk score.

product_exposureread-only

CVE exposure of one vendor and product: severity, KEV and PoC counts, CVSS, EPSS, the worst risk score, the top CVEs and the endoflife.date support dates.

cpe_searchread-only

Find the CPE vendor and product names that hold a text, ranked by vulnerable CVE count.

cvss_calculatorread-only

Decode a CVSS v3.0/v3.1 vector into its base metrics and recompute its base, temporal and environmental scores.

watchlist_edit

Add, remove, list or clear the items this API key watches: CVEs, products, CVE searches, packages, domains and IP addresses.

watchlist_events

Report what changed on the items this API key watches, such as a new advisory for a package or a certificate about to expire, oldest first.

privacy_my_dataread-only

What this server keeps about the caller: the hash its credits are counted under, the rate limit left in this hour and the privacy policy.

vendor_key_edit

Save, delete or check your own Shodan and AbuseIPDB keys, which the ip_lookup tool uses.

password_checkread-only

Check a password's SHA-1 against Have I Been Pwned's Pwned Passwords list.

dns_lookupread-only

Look up a domain's DNS records: A, AAAA, MX, NS, TXT, CNAME, SOA and CAA.

dns_takeover_checkread-only

Check a host name for subdomain takeover through a dangling CNAME.

email_auth_checkread-only
