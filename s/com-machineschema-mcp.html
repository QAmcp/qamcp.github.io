What it can do

10 tools, in the server's own words.

search_entriesread-only

Full-text search across hardware, controllers, protocols, standards, alarm codes, terms and manufacturers.

get_entryread-only

Return the full structured record for one id: typed spec values, sources and verification status.

find_hardwareread-only

Find hardware matching numeric limits, manufacturer, controller and supported protocols, e.g.

list_facetsread-only

Valid values, with counts, for find_hardware filters: categories, manufacturers, controllers and protocols.

compareread-only

Align 2 to 5 entries of the same type into one table of numeric spec values with units, plus each entry's verification status and sources.

check_limitsread-only

Check planned payload, reach, TCP speed, repeatability, ambient temperature or IP rating against a robot's published limits.

get_relatedread-only

List entries connected to an id, in both directions: a robot's manufacturer, controllers and protocols, a controller's robots and alarm codes, or a base model'…

lookup_alarmread-only

Find what a controller alarm or error code means and what to check.

calculate_metricread-only

Evaluate a formula entry, such as OEE, with your inputs.

get_schemaread-only

Return the JSON Schema every entry of a type conforms to.
