What it can do

8 tools, in the server's own words.

search_componentsread-only

Find existing, licence-cleared code (functions, classes, handlers, modules) mined from real open-source repositories, before writing it from scratch.

find_similarread-only

Find alternatives to a component you already have: other licence-cleared implementations of the same job, to compare scores, licences and stacks.

list_categoriesread-only

List the function tags (categories) in the library with how many components each has; the values search_components accepts as `category`.

get_componentread-only

library_statsread-only
