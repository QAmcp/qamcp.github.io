A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

27 tools, in the server's own words.

search_docsread-only

Search the FynePDF API and MCP documentation: actions, parameters, pricing, files, jobs and errors.

list_actionsread-only

Every action FynePDF can run on a file (the REST API's job steps), with what it takes, what it makes and its price in API credits.

app_readyread-only

FynePDF's in-chat cards say once which host bridge they run in, for diagnosis.

preview_fileread-only

The first pages of a PDF as images, for FynePDF's result viewer.

upload_file

Bring a file into FynePDF.

import_file_from_url

Fetch a PDF, Office file, image or EPUB from a public link into FynePDF and get its file_id.

get_fileread-only

A file's details and a fresh download link (valid 1 hour).

list_library_filesread-only

Files saved in the person's FynePDF Library, newest first (pinned on top).

list_filesread-only

Files on FynePDF from the last 24 hours, newest first: what the person dropped in the upload box, other uploads and imports, and results.

save_to_library

Keep a result in the person's FynePDF Library (fynepdf.com/library), so it isn't deleted after 24 hours.

merge_pdfs

Join PDFs into one, in the order given (file_ids, then files, then file_urls).

split_pdf

Split a PDF into parts by page ranges ("1-3", "4", "5-9") or into parts no bigger than max_part_mb.

edit_pages

Change a PDF's pages (counted from 1): delete pages, keep only some pages, put pages in a new order (pages left out are dropped), or rotate all pages or a rang…

stamp_pdf

Number the pages, stamp a text watermark on every page, or both in one go.

compress_pdf

Make a PDF smaller: at a level (low, medium, high) or under a target size in MB.

protect_pdf

lock: add a password needed to open it.

redact_pdf

Remove text for real, not just cover it: name the exact text to remove, or describe it ("all names, emails and account numbers") and FynePDF finds it.

convert_from_pdf

Turn a PDF into Word (.docx), Excel or CSV (tables found on the page), images (PNG/JPEG in a ZIP), Markdown, EPUB, PDF/A (archival), LaTeX, or a grayscale PDF.

convert_to_pdf

Make a PDF from Word, Excel or PowerPoint files, images (one page each, in order), an EPUB, or a public web page (url).

ocr_pdf

Add a text layer to scanned pages, so the text can be searched, copied and read by AI.

create_pdf

Turn Markdown or HTML you write into a well-set PDF: a report, invoice, letter, resume or plain document.

sign_pdf

Stamp a signature image (PNG or JPEG) on a page: at a named spot (bottom-right by default) or at x and y in points from the top-left corner.

ask_pdfread-only

Answer a question from the document only, citing pages.

summarize_pdfread-only

A plain summary and key points, each with the pages it comes from.
