What it can do

60 tools, in the server's own words.

create_site

Create empty site; seeds brief.

get_siteread-only

Site detail, stats, publicUrl, brief head (default-on), and readiness flags.

update_brief

Update `_intent/site.md` (site brief) or a page brief when `page` is set.

get_analyticsread-only

Read-only traffic overview (default) or full breakdowns via include[]; optional bot id for crawler page drill-down.

update_site

Update site settings: title, keyConvention, or editingMode ('live' = each editor save publishes immediately; 'staged' = saves stay drafts until publish_site).

rename_site

Rename the site slug (public hostname {slug}.dotsy.site).

publish_site

Publish draft to live.

get_draft_statusread-only

Pending draft changes: content keys and routes with status.

discard_drafts

Discard unpublished drafts: all (omit key/keys/routes), one content key (key), or a selection (keys, routes).

delete_site

Permanently delete site; confirmSlug must equal slug.

bulk_put_content

Stage many content keys (pages, layouts, fragments).

get_site_manifestread-only

Content keys + hashes only (optional routes=true) — static files live in list_assets, not manifest.

find_replace

Case-insensitive find→replace across pages in one staged commit.

search_contentread-only

Find pages containing a phrase (grep without reading bodies).

graduate_site

Enable site search & collections (kv → do-sqlite), one-way.

apply_changeset

Stage writes[] + deletes[] in one call; attach routes via writes[].route.

import_site_from_url

Import URL to draft.

get_structure_statusread-only

Flat vs structured page counts; informs user — do not auto-run analyze/apply while requiredDecision pending.

structure_site_analyze

Propose shared layout + fragments; persist:false first.

decompose_analyze

Deprecated — use structure_site_analyze.

structure_site_apply

Rewrite flat pages to layout + fragments (draft).

get_structure_resultread-only

Last structure apply job result (structuredKeys, conflicts, partial).

adapt_site_analyzeread-only

Propose nav wiring + blog collectionization for an imported mirror (draft, opt-in).

adapt_site_apply

Apply the adapt proposal (draft): wire nav into the menu store and/or rewrite the blog index to a live .
