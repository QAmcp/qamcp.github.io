  • Overall it scored 90/100 on 1 Nov 2026.

A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

60 tools, in the server's own words.

create_site

Create empty site; seeds brief.

get_siteread-only

Site detail, stats, publicUrl, brief head (default-on), and readiness flags.

update_brief

Update `_intent/site.md` (site brief) or a page brief when `page` is set.

get_planread-only

Read-only workspace plan and pooled usage; pass slug for this site's add-ons.

get_analyticsread-only

Read-only traffic overview (default) or full breakdowns via include[]; optional bot id for crawler page drill-down.

set_analytics_provider

Connect a third-party analytics provider (GA4, Plausible, Fathom, Umami) or remove it (provider 'none').

get_custom_coderead-only

Read the site-wide custom code: `draft` (what the next publish puts live) and `published` (what visitors get now) for both boxes — head (before ) and body (bef…

set_custom_code

Set site-wide custom code: `head` goes before and `body` before on every page, on every layout.

update_site

Update site settings: title, keyConvention, or editingMode ('live' = each editor save publishes immediately; 'staged' = saves stay drafts until publish_site).

rename_site

Rename the site slug (public hostname {slug}.dotsy.site).

publish_site

Publish draft to live.

get_draft_statusread-only

Pending draft changes: content keys and routes with status.

review_changes

Review queue: what changed and isn't live yet.

discard_drafts

Discard unpublished drafts: all (omit key/keys/routes/menus), one content key (key), menu draft only (menus:true), or a selection (keys, routes).

delete_site

Permanently delete site; confirmSlug must equal slug.

bulk_put_content

Stage many content keys (pages, layouts, fragments).

get_site_manifestread-only

Content keys + hashes only (optional routes=true) — static files live in list_assets, not manifest.

find_replace

Case-insensitive find→replace across pages in one staged commit.

search_contentread-only

Find pages containing a phrase (grep without reading bodies).

graduate_site

Enable site search & collections (kv → do-sqlite), one-way.

apply_changeset

Stage writes[] + deletes[] in one call; attach routes via writes[].route.

import_site_from_url

Import URL to draft.

get_structure_statusread-only

Flat vs structured page counts; informs user — do not auto-run analyze/apply while requiredDecision pending.

structure_site_analyze

Propose shared layout + fragments; persist:false first.
