What it can do

17 tools, in the server's own words.

create_mock

Create a hosted mock from an OpenAPI 3.0/3.1 or Swagger 2.0 document (YAML or JSON), from TypeScript types (interfaces, types, enums: CRUD routes derived, or a…

list_mocks

List the connected account's mocks (API token required), with their URL, routes and expiry.

get_mock

Details of a mock: routes with identifiers, behaviour, lock, sample generated bodies per route.

call_mock

Call a route of the mock like an HTTP client would and return the status, the x-loutre-* headers and the body.

set_behavior

Change a mock's behaviour: default status, latency, jitter, error rate, persistent writes, and per route status, latency, hand-written bodies, rules.

set_response

Set the JSON body a route returns for a given status (hand-written response); a null body restores the generated response.

add_rule

Add a conditional response to a route: when the request matches the conditions (query, header, path param, body field), the mock answers with this status, body…

clear_rules

Remove every conditional rule of a route.

regenerate_mock

Generate a new data set (new seed), for the whole mock or for one route and the routes sharing its collection.

get_requests

The latest requests received by the mock, most recent first: method, path, query, status, headers and body as received (body cut at 8 KB), where the answer cam…

replay_request

Replay a request from the log exactly as it was received (same method, path, headers and body) against the mock as it is now, and return the answer.

clear_requests

Empty the mock's request log.

sync_mock

Re-read the schema at the mock's source URL now and update the mock if it changed (routes, fields; settings kept, persisted writes forgotten).

set_domain

Serve the mock under the account's own hostname (Pro): declares it at Cloudflare and returns the CNAME to create (hostname → target) plus the current status; c…

reset_state

Forget persisted writes (POST, PUT, PATCH, DELETE): the generated collections come back as they were.

set_access

Lock a mock with a token (private) and/or restrict the allowed browser origins.

delete_mock

Permanently delete a mock and its kept schema.
