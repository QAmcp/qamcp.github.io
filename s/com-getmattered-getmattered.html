A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

40 tools, in the server's own words.

getmattered_get_matchesread-only

Lists the user's matched jobs, best fit first and mixed across companies, so scores are not in strict order.

getmattered_apply

Applies to one job by job_match_id or job_url, on the employer's own hiring system.

getmattered_get_applicationsread-only

Lists the user's applications and where each stands, or reads one by application_id.

getmattered_approve_applications

Submits waiting applications to their employers under the user's name.

getmattered_get_accountread-only

Reads the signed-in user's account id, display name and sign-in email, plan, token balance, applications left, job preferences and readiness: whether a resume …

getmattered_get_profileread-only

Reads which account this connection is signed in as, which tells connected accounts apart.

getmattered_reject_applications

Skips applications waiting for review that the user said no to.

getmattered_cancel_applications

Stops applications that are queued, being prepared or waiting for review, so they are never submitted.

getmattered_refine_application_documents

Rewrites the tailored resume or cover letter of unsent applications from the user's own words.

getmattered_reprepare_applications

Builds the documents and form answers of applications again.

getmattered_set_application_stage

Records a stage the user reports on their own tracker.

getmattered_set_resume

Sets the base resume every application is tailored from, from exactly one source.

getmattered_save_matches

Saves matches for later.

getmattered_skip_matches

Skips matches the user does not want, with an optional reason that improves later matches.

getmattered_unsave_matches

Removes matches from the saved list.

getmattered_restore_matches

Brings back skipped matches.

getmattered_get_inboxread-only

Reads employer emails sent to the user's GetMattered address, or one conversation with drafted replies by message_id.

getmattered_reply_to_email

Sends the user's reply to an employer from their GetMattered address.

getmattered_score_resume

Scores a resume for ATS compatibility, against a posting or in general.

getmattered_analyze_job_description

Extracts a posting's keywords and requirements, with must-haves marked.

getmattered_optimize_resume

Rewrites a resume for ATS screening, for one posting or in general.

getmattered_generate_interview_questions

Builds interview preparation for a role and company, by application_id or job title and company.

getmattered_translate_resume

Translates a resume into another language and saves it as a separate document.

getmattered_update_job_preferences

Changes what GetMattered looks for and searches again.
