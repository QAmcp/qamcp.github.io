A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

5 tools, in the server's own words.

list_modelsread-only

List LLMs tracked by Agent Cost Hub with API list prices per 1M tokens.

get_model_priceread-only

Current API list price of one model (input, output, cached input per 1M tokens) plus example monthly agent costs.

estimate_costread-only

Estimate the monthly API cost of an AI agent or chatbot on one model.

compare_modelsread-only

Compare 2-5 models on price and (optionally) on the monthly cost of one workload.

cheapest_models_forread-only

Rank models by monthly cost for a workload.
