A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

6 tools, in the server's own words.

new_device_nameread-only

Get an unused device name (like amber-otter-4821) with its ingest, read, live-stream and chart URLs.

publish_reading

Store one reading for a device, exactly as POST /add/{device} would.

get_latestread-only

The most recent reading from a device, when it arrived (unix seconds) and how long ago, plus its chart URL.

get_historyread-only

Numeric history for a device over the last N hours (up to 2208, ~92 days): min/max/mean/first/last per metric, and a downsampled series where each point is the…

wait_for_readingread-only

Wait until a device sends a new reading, then return it.

list_recent_devicesread-only

The 20 most recently active public devices with their latest readings.
