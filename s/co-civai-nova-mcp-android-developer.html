  • Its source code and packages.

  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

38 tools, in the server's own words.

list_tracks

List an app's release tracks and their track_id — call this first to find the track_id other release tools need.

get_track

Get one release track's current state by track_id, including every release on that track with its release_id, name, status and lifecycle state.

create_release

Create a new draft release on a track.

upload_bundle

Upload a signed .aab.

check_package_name_availability

Check whether a package name is available before creating a new app.

create_app

Create a brand-new Android app on Google Play — the one thing the official Android Publisher API cannot do.

list_apps

List apps on this Play Console developer account.

list_accounts

List which Google accounts are signed in to this browser session, with their X-Goog-AuthUser slot index.

update_store_listing

Update an app's main store listing (title, short/full description) for one language using Play Console's own web session.

update_store_listing_screenshots

Reorder or remove an app's existing store-listing screenshots for one language.

get_release

Get a release's current state, including currently-attached artifacts and validation status — check this before start_rollout.

start_rollout

Roll out a release — this IS Android's publish action for the release.

update_ads_declaration

Declare whether the app contains ads, using Play Console's own web session.

update_sign_in_details

Declare whether any part of the app is restricted (requires account sign-in, payment, referral/QR codes, OTP, biometrics, or actions on another device).

update_target_audience_content

Declare the app's target audience & content, using Play Console's own web session.

update_policy_declaration

Set a simple Yes/No App content policy declaration, using Play Console's own web session.

update_content_rating

Submit and apply the mandatory IARC content rating questionnaire, using Play Console's own web session.

update_privacy_policy

Set the app's privacy policy URL, using Play Console's own web session.

update_data_safety

Submit the Data safety declaration.

update_none_option_declaration

Declare 'none of the above' for a multi-select feature-checklist App content declaration, using Play Console's own web session.

upload_screenshot_asset

Upload an image into the app's Asset Library.

promote_release

Promote an existing release to another track WITHOUT re-uploading the bundle.

get_pre_submit_status

Read-only: what Google Play still requires before this app is review-eligible.

upload_store_listing_graphic

Upload an image AND attach it to a store-listing slot in one call — phone screenshot, feature graphic or app icon.
