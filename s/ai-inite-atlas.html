A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

atlas_searchread-only

Filter the INITE Atlas without a model, when you know the shelf or the properties a tool must have: a phrase, a category, and slices that must all hold.

atlas_changesread-only

What changed among the tools in the INITE Atlas: prices up or down, free plans added or dropped, OpenAPI specs published, MCP servers listed.

atlas_couponsread-only

Live discount codes for AI tools in the INITE Atlas, optionally for one domain.

atlas_report

Say an Atlas card is wrong, or ask it off.

atlas_compareread-only

Preview a price comparison of 2-5 Atlas tools for a usage scenario, computed without a model from plan editions checked against the vendors' own pricing pages.

atlas_dataset_getread-only

Read a dataset: a published one by anybody (its snapshot with freshness and the default result), a draft only by its owner (config, configVersion, preview).

atlas_dataset_changesread-only

Confirmed changes between the revisions of a published dataset, newest first: plans added, removed, or which fields moved.

inite_connectread-only

How to add another INITE MCP server to this client, when the person wants something this one does not do.
