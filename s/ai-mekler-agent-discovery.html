What it can do

24 tools, in the server's own words.

search_services

Find Mekler paid operations for a task, including exclusions and useful combinations.

get_service

Get a complete public service or operation contract by slug, operation ID, name, or endpoint URL.

scan_origin

Start or recover an asynchronous x402 conformance scan.

get_scan_statusread-only

Read a conformance job state with job_id and recovery_capability.

get_scan_reportread-only

Read a completed public cached report by report_id.

list_conformance_checksread-only

Read the versioned 25-check linter and separate 14-check compliance catalogs, grading rules and unknown-evidence semantics.

search_listingsread-only

Search scanned x402 services by text, host, category, grade, owner verification or featured status.

retrieve_listingread-only

Retrieve one visible scanned service, current grades, first seen, scan count and the latest 100 grade observations.

export_listings

Export up to 10000 visible scanned x402 services with grade history, first seen, scan counts, provenance and explicit truncation.

list_grade_changes

Read ordered new, grade_changed and rescanned events with previous grades and scores.

start_ownership_proof

Start a one-hour domain challenge bound to your private random 32-byte requester key in lowercase hex.

confirm_ownership_proof

Confirm a one-hour domain challenge with the same private requester key.

update_listing_preferences

Use X-Mekler-Listing-Control and the expected revision to hide a listing, suppress branding or revoke access.

get_trial_offerread-only

Read the adjustable free-use offer, wallet authentication, allowance and explicit paid transition.

get_trial_accessread-only

Get the service request and standard wallet-auth instructions.

rotate_trial

Write: request a wallet-rotation challenge with old_wallet/new_wallet/request_id; then submit old_proof/new_proof signed with both keys.

referral_accept_terms

Accept a newer version of the referral terms to keep earning.

referral_acknowledge

Mark notices already served by referral_notices as read up to a cursor.

referral_notices

Read published program notices and the referrer's private account events.

referral_receipts

Page through a referrer's commission receipts, oldest first.

referral_register

Register a wallet as a Mekler referrer and receive a referral code.

referral_rotate

Move a referral registration to a new wallet without losing history.

referral_status

Read a registered referrer's code, referral link, accepted versus current terms and whether action is required.

referral_programread-only

Read current Mekler referral availability, terms and commission offer.
