A test can only see what the server shows from outside, not what it does with your data behind the scenes. Connect servers from makers you trust.

What this test does not check

  • Its source code and packages.
  • What a tool quietly does behind the scenes, such as writing a file or calling another service.
  • Instructions hidden inside live tool answers. We only look for those in tool descriptions.
  • Hidden instructions worded in a way our list doesn't know yet.
  • Tools that could change something. Those are read, never run.

What it can do

10 tools, in the server's own words.

canopy_check_bookableread-only

Given businesses you already found for the user (name plus phone, website or address), report which ones can be booked through Canopy and how (booking_mode).

resolve_businessread-only

Match one business the user named to its Canopy listing, by phone, website, or name (add the city, state or ZIP code when you know it).

get_availabilityread-only

List open appointment slots for a Canopy business, optionally for one service and one location, between two dates.

request_booking

Start a booking with a Canopy-connected business.

propose_times

Propose preferred times to a business that reviews booking requests.

request_callback

Request a callback from a business.

get_request_statusread-only

Check the status of a booking request (preferred times or callback).
