What it can do

4 tools, in the server's own words.

validate_npiread-only

Offline check of up to 50 NPI numbers: 10 digits and the Luhn check digit (prefix 80840).

lookup_npiread-only

Fetch 1-20 providers by NPI number from the live CMS NPI Registry: name, credential, status, primary specialty (taxonomy), practice address and phone.

search_providersread-only

Search the live NPI Registry by first/last name, organization name, specialty (taxonomy description as the registry writes it, e.g.

count_by_specialtyread-only

How many providers does the NPI Registry list for a specialty, optionally in a state or ZIP prefix?
