What it can do

8 tools, in the server's own words.

search_liliphant_docsread-only

Search the Liliphant API documentation with a natural-language question.

get_liliphant_api_docsread-only

Browse the Liliphant API API docs, one level at a time.

call_any_read_api_of_liliphantread-only

Read from any Liliphant API API endpoint with a GET request for the user and return its response.

call_any_api_of_liliphant

Send a POST, PUT, PATCH or DELETE request to any Liliphant API API endpoint for the user and return its response.

get_meread-only

Returns who is signed in and every company they can open, with their role in each.

list_meetingsread-only

Lists the analysed meetings the caller may see, as cards, newest first, with the filter choices the Meetings screen offers.

ask_a_questionread-only

Answers a plain-language question from the company's processed meetings, with a headline, a short answer, an optional chart and the quotes it is based on.

quickstart-liliphantread-only

Liliphant API quickstart: read the user's meetings and ask questions answered from what people actually said.
