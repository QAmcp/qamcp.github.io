A program on your computer, not a link? Use --stdio "npx -y your-server".

Sheet 4 of 6 · For teams

Publish a server for customers? Check it on every change.

When your MCP server breaks, your customers' AI agents break with it. QAmcp runs in GitHub on every pull request, comments with the score, and fails the build if the server got worse or a tool disappeared.

  • Never runs risky toolsOnly tools labeled read-only, whose names and descriptions agree.
  • Sends nothing elsewhereNo tracking, no account, no AI. Only your server hears from it.
  • Your login stays yoursYou sign in on your server's own page; nothing is stored anywhere else.
  • Open sourceMIT licensed. Read every check before you trust it.

on: pull_request
jobs:
  qamcp:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: QAmcp/qamcp-cli@v0
        with:
          url: https://your-server.com/mcp
          fail-under: 80

Sheet 6 of 6 · Questions

Questions about QAmcp

What is QAmcp?

A free, open-source tester for MCP servers. It connects to a server the way an AI app does and tells you, in plain words, what is broken: connection, tool descriptions, safety labels, hidden instructions, bad inputs, leaked secrets and speed. Every result is a hard fact, and no AI judges anything.

Is it free?

Yes. The browser test, the command-line tool (npx qamcp-cli), the GitHub check and the directory are free. The code is open source under the MIT license.

Does it send my data anywhere?

No. It talks only to the server you test, and to its login page if it has one. There is no tracking and no telemetry. On the website, the test runs on our test service and the report is kept so you can share its link.

Can it change or delete anything on my server?

By default it only runs tools the server labels read-only, and it never runs tools that sound destructive, like delete_account, in any mode. With --look-only it calls no tools at all.

Can it test local servers, or servers behind a login?

Yes. Local servers from the terminal: npx qamcp-cli --stdio "your start command". Servers behind a login: add --login to sign in through your browser, or --header with an API key.

How is the score calculated?

Each check is worth points: a pass earns all of them, a warning half, a failure none. Checks that could not run don't count either way, and serious problems such as hidden instructions or leaked secrets cap the score. The full rules are on the How it works page.

How is it different from MCP Inspector?

MCP Inspector, the official tool, lets you connect and call tools by hand, which is ideal for exploring and debugging. QAmcp runs a fixed set of checks automatically and gives a score you can repeat on every change. They work well together.

My server is in the directory. Can I have it removed?

Yes. Open an issue on GitHub and we'll take it off the list. Scores in the directory are never changed for money.

Who makes QAmcp?

Abhiram Reddy, a solo founder, building it in the open. Found a wrong result? Report it on GitHub: being fair to every server matters most.
