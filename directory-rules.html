How the directory works

Every server here was actually connected to and tested, not just read about. These are the rules for how servers get listed, how the order is decided, and what we never do. They're public so you can hold us to them.

Getting listedHow the order is decidedKeeping it fairWhat never changes
Sheet 2 of 5 · Getting listed

Every new server, tested the day it appears

  • From the official MCP RegistryEach day we test new servers published to the official MCP Registry and give each one a page with its result.
  • The same test anyone can runIt's the free, open-source npx qamcp-cli in safe mode: only tools labeled read-only are run, and nothing is changed or deleted.
  • Behind a login? Still listedWe check what we can from outside and mark it "needs login" instead of giving it a low score. The owner can test everything behind the login.
  • Kept up to dateListed servers are re-tested on a rotation, so scores follow what's live. Every page shows when it was last tested.
  • Coming soonAdding a server by pasting its link, and claiming your page to add a description, logo and links, and to reply to reviews.
Sheet 3 of 5 · How the order is decided

Relevance, then the test result

  • 1. What you searched forA search for "calendar" shows calendar servers first, by their name, description and tool names. The score only sorts servers that match.
  • 2. The scoreHigher scores come first. The score comes only from the test.
  • 3. How recent the test isResults only start to count a little less once they're more than 60 days old.
  • New servers get 90 daysEvery new server spends 90 days on the "New" shelf, shuffled every day so no one is stuck at the bottom.
  • No upvotesVotes are easy to fake, so there are none.
  • Size doesn't matterA small server that does one thing well ranks the same as a big one. More tools isn't better.
Sheet 4 of 5 · Keeping it fair

Rules for everyone, including us

  • One server, one listingCopies of the same server under different names are merged into one.
  • No cheating the testA server that behaves differently when it sees our tester is removed. Anyone can re-run the same open-source test to check.
  • Security problems go to the owner firstIf we find a hidden instruction or a leaked secret, we tell the owner privately and wait 7 days before it shows here.
  • Not answeringA server that doesn't answer 3 tests in a row is marked "not answering". After 30 days it leaves the main lists, and comes back when it answers again.
  • Think a result is wrong?Tell us. If QAmcp made the mistake, we fix the tester for everyone and test again.
  • Our own serversServers made by QAmcp, like our demo, are not ranked here.
Sheet 5 of 5 · What never changes

Our promises

  • Scores come only from the testNobody edits a score by hand, for any reason.
  • Free to list, free to lookBeing listed and browsing the directory are free.
  • Every new server gets its 90 daysNo exceptions, no shortcuts.
  • Your server, your callIf you own a server and don't want it listed, ask and we'll remove it.
  • Rules in the openThese rules are public, and any change will be announced here before it happens.

Have a concern about a listing?

Want your server removed, or think a result is wrong? Tell us on GitHub and we'll look at it.
