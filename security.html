Three ways to run it, three answers

How you run itWhat leaves your networkWhat we keep

Website test on qamcp.devThe server link and the results pass through our test serviceThe report (link and results). API keys and login passes are never saved

For a server inside your company, run the terminal tool or the Docker image on your own machines: it can test servers that are only reachable inside your network, and nothing comes to us.

Sheet 3 of 5 · What it never does

What QAmcp never does

  • Never runs tools that could change your data in its default safe mode: only tools labeled read-only, and only when their name, description and inputs agree. --look-only runs no tools at all.
  • Never sends your data to an AI. Every check is plain code that measures facts.
  • Never tracks you. No analytics in the tool, no cookies or tracking scripts on the website.
  • Never sells or shares your data, and never changes a score for money.
Sheet 4 of 5 · How it's protected

How it's protected

  • Open source (MIT). Your team can read every line before approving it: github.com/QAmcp/qamcp-cli.
  • Encrypted in transit. The website and the test service only work over HTTPS.
  • Secrets stay in memory. An API key or login pass given to the website test is used for that one test and never written to disk.
  • No reaching inside. The website test refuses links that point into private networks, so it can't be used to reach internal machines.
  • Limits per visitor, so one person can't flood a server through us.
  • A careful build. The code's dependencies are watched for security updates, and the GitHub Actions it uses are pinned to exact versions.
Sheet 5 of 5 · What we don't have

What we don't have yet

QAmcp is young and made by one person. We don't have a security certification such as SOC 2 or ISO 27001, and we won't claim one until we do. If your company needs a questionnaire filled in, a data agreement or a private setup, email hi@qamcp.dev.

Found a security problem in QAmcp?

Please tell us privately, as described in our security policy, not in a public issue.
