Sheet 2 of 6 · What it watches

What Monitor watches

  • Is it up?A quick check every 5 minutes that runs no tools. After 2 failed checks in a row, you get a "Down" email; when it answers again, a "Back up" email with how long it was down.
  • The full test, every hourThe same test as the free one: connection, MCP version, tool descriptions and inputs, safety labels, hidden instructions, bad-input handling, leaked secrets, speed, login setup, resources and prompts.
  • Score dropsWhen the score falls by 5 points or more, with exactly which checks got worse.
  • Tool changesA tool added, removed or renamed, an input or required field that changed, a safety label that flipped: the exact before and after, even if you didn't change it yourself.
  • SecurityA hidden instruction that appears in a tool description, or a secret that starts showing up in an error message, and the moment it's gone again.
  • Safe, alwaysOnly tools labeled read-only are ever run, and never anything that sounds like it deletes. Monitor never changes your data.

What an alert looks like

This is a real Monitor email, for our own test server that we switched off on purpose.

From: QAmcp Monitor · Subject: [Down] api.acme.ai is not answering

DOWN: api.acme.ai is not answering
────────────────────────────
What happened
   Your MCP server stopped answering at 02:14 UTC. It failed 2 checks in a row.
What it means
   Right now, AI apps that use this server get errors instead of answers.
What to do
   Check that the server is running and reachable. You don't need to do
   anything here: we keep testing and email you again the moment it answers.
Details
   What we saw: the connection timed out

Sheet 6 of 6 · Questions

Questions

Does paying change my score in the directory?

No, never. Every server gets the same test, and scores are never changed for money. The directory rules

Can Monitor break or change my server?

No. It only runs tools your server labels read-only, and only when their name, description and inputs agree. The 5-minute check runs no tools at all.

My server needs a login. Does Monitor work?

Today it watches whether the server is up and whether its login setup still follows the MCP rules. Testing the tools behind the login is coming.

What do you keep about me?

Your email, your server's link and its test history. No AI reads any of it. Privacy
